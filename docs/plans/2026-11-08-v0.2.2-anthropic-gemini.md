# v0.2.2: the Anthropic and Gemini adapters and `/v1/messages`

> Steps use checkbox (`- [ ]`) syntax for tracking. Follow the rules in AGENTS.md.

**Goal:** Claude Code works against transponder with only `ANTHROPIC_BASE_URL` changed, and any caller (OpenAI or Anthropic dialect) can reach Anthropic, Gemini, OpenAI-compatible servers or echo, with tools, streaming and usage.

**Architecture:** Same shape as chat completions. `/v1/messages` peeks the model, resolves a route, and forwards the raw body when the target speaks Anthropic (native passthrough keeps thinking blocks, `cache_control` and beta fields). Otherwise the request goes through the canonical types, which now carry a system prompt, tools, tool calls and tool results. Each dialect package converts its wire format to and from canonical in both directions, so an adapter uses the same code as the server. Gemini is always translated. Budgets, token and rate limits (v0.2.3) and fallback (v0.2.4) stay out.

**Tech Stack:** Go 1.26, standard library. No new dependencies.

**Spec:** [docs/design.md](../design.md) sections 5, 6, 10, 13 and 15.

## Global Constraints

- Anthropic: base URL `https://api.anthropic.com/v1`, `x-api-key`, `anthropic-version` forwarded from the caller or `2023-06-01`, `anthropic-beta` forwarded. Errors are `{"type":"error","error":{"type":...,"message":...}}` with the types `invalid_request_error` 400, `authentication_error` 401, `permission_error` 403, `not_found_error` 404, `request_too_large` 413, `rate_limit_error` 429, `api_error` 500, `overloaded_error` 529.
- Gemini: base URL `https://generativelanguage.googleapis.com/v1beta`, `x-goog-api-key`, `models/{model}:generateContent`, `:streamGenerateContent?alt=sse`, `:batchEmbedContents`. Tool schemas go in `parametersJsonSchema`. A function call's `thoughtSignature` travels inside the tool call id (`tsig_` plus unpadded base64url) so it comes back on the next turn.
- Canonical finish reasons: `stop`, `length`, `tool_calls`, `content_filter`.
- Translated requests to Anthropic drop `temperature` and `top_p` (current models reject them) and default `max_tokens` to 8192 when the caller sets none. Dropped fields are logged at debug.
- Content a target cannot take on the translated path (images, documents) is 400 `unsupported`. Thinking blocks in history are dropped when translating.
- Prices from the vendors' pages on 2026-11-08; Gemini at the up-to-200k tier.
- No network in unit tests. Coverage at 80% or more. One PR from `feat/anthropic-gemini`, then release v0.2.2.

## Review Focus

1. Claude Code's request (system blocks with `cache_control`, `thinking`, tools, `anthropic-beta`) reaches Anthropic byte for byte apart from `model`, and its stream comes back with the `event:` lines intact.
2. A tool call made through Gemini or OpenAI keeps its id across the next turn, so the tool result matches.
3. An Anthropic stream that stops before `message_stop` ends with an `error` event, and usage is still recorded.
4. Usage from Anthropic streams: input and cache tokens from `message_start`, output from the last `message_delta`.
5. An upstream error on `/v1/messages` reaches an Anthropic client in the Anthropic error shape, never the OpenAI one.
