# Security

Please don't report a security problem in a public issue.

Use GitHub's private vulnerability reporting instead: [report a vulnerability](https://github.com/raven-clown/transponder/security/advisories/new), or open the Security tab of this repository and choose "Report a vulnerability". You'll get a first answer within three days.

Published advisories are listed at https://github.com/raven-clown/transponder/security/advisories.

Fixes go to the latest release. Before 1.0, only the latest minor version gets security fixes.
